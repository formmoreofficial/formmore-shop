# Pictures for the website

Upload your pictures into this folder with exactly these names. Each name works as `.png`, `.jpg` or `.webp`
(for example `intro-generic.webp`), so you only need to match the part before the dot.
Until a picture is here, its box on the website shows its file name, so you can see where each one goes.
Keep each file small, about 300 KB (WebP or JPG).

## 1. Intro slide: "Introducing: the Prompt Alchemy"
Square, 1024 × 1024 or larger. The whole picture shows.

| File name | Where it shows |
|---|---|
| `intro-generic` | Left picture, "Generic image" |
| `intro-alchemy` | Right picture, "With Prompt Alchemy" |

## 2. Dashboard: the two big tiles
Landscape 3:2, 1536 × 1024 or larger. Keep the subject centered in the top third; the words cover the rest.

| File name | Where it shows |
|---|---|
| `dashboard-design` | Tile "Start with a design" |
| `dashboard-idea` | Tile "Just an idea" |

## How to add or change a picture on GitHub
1. Open this `images` folder on GitHub and choose **Add file → Upload files**.
2. Drop in the picture, named as above. To replace one, upload a file with the same name.
3. Press **Commit changes**. Vercel puts the new picture online in about a minute.

The list the website reads is at the top of `index.html` (search for `window.MEDIA`). You only need to edit it
if you want a different file name.
